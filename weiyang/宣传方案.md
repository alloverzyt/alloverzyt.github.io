**官方推文只有一次，这是最贵的资源。**

所有平台、所有内容、所有节奏，都是为了两件事：

## 一、我们要解决的传播问题

活动本身的策划由总方案负责，宣传组要解决的是三个独立的难题：

| 难题 | 具体表现 | 传播对策 |
|---|---|---|
| **不知道有这场活动** | 义卖在宽窄巷子，对校外人群是完全陌生的 | 悬念期先造势，再用官方推文一次性引爆 |
| **知道但不感兴趣** | "又是卖东西做公益" | 不用口号，用**具体的物品和场景**（一本书、一个发圈、一张手写卡片） |
| **感兴趣但不信** | 怀疑是学生自嗨、钱去哪儿了 | 四重确定性：官方推文授权 + 团委盖章 + **24h 内公示收支** + **35 项公开可查的团队荣誉** |

> 第三条最容易被忽略，但它是**信任的支点**。爱心义卖最怕的就是"钱说不清"。把公示做成公开动作，等于提前把质疑堵死了。

**第四条（荣誉背书）是本轮新增的补丁，需要特别说明它的作用边界：**

| 背书类型 | 它担保的是 | 它不能担保的是 |
|---|---|---|
| 宽窄巷子官方推文 | **平台**——这个地方可信、这场活动合规 | 不能担保"我们"是谁、钱交给谁 |
| 团委盖章 | **流程**——程序正规、经得起查 | 不能担保"我们"是谁 |
| 收支公示 | **钱**——账目可查、钱没被挪走 | 不能担保"我们"是谁 |
| **团队荣誉（35 项）** | **我们**——这群人是谁、是不是做事的人 | 不能担保"钱" |

前三条解决的是"钱安全吗"，**第四条解决的是"你们凭什么"**。宽窄巷子的官方推文替我们担保了场地与合规，但**官方推文里不会出现我们的名字**——路人划到那条推文时，看到的是一个摊位，不是一群值得信任的人。

所以荣誉不是"锦上添花"，它填补的是官方背书**结构上无法填补**的那个洞。35 项获奖全部来自第三方榜单与公示（知行计划、榜样 100、全国重点团队、软件学院实践评比等），意味着它**不是我们自己说的**，任何人都能查证。宣传口径统一为"公开记录荣誉（部分记录）"，不得写"共获 35 项奖"这类会被理解为穷举所有荣誉的表述。

配套产出：荣誉墙海报（`海报/06`）、推文第 04 章「这支队伍是谁」、社媒「信任背书补充分支」。

## 五、摄影组（6 人）

详细执行见《摄影组执行手册》。核心设计：

| 编号 | 角色 | 核心产出 |
|---|---|---|
| A | 组长 / 主摄 | 主视觉图、推文头图 |
| B | 摊位特写 | 义卖过程、物品细节 |
| C | 巡游跟拍 | 动态素材、**抖音短视频主力** |
| D | 人像组 | 路人合影、**UGC 引擎** |
| E | 物资物料 | 摊位全景、准备瞬间 |
| F | 数据记录 | 账目凭证、捐赠瞬间 |

**三条设计原则：**
1. **摄影组不承担义卖岗位**——专注拍摄，避免与值班冲突；
2. **B 静 C 动**——静态出小红书，动态出抖音，两组素材不重复；
3. **D 是转发动机**——路人合影是唯一能带来自然流量的素材，必须明确要求其邀请路人。

**素材交付硬要求**：活动当天 17:30 前完成初剪，当晚 21:00 前认领剪辑任务，次日交付成片。这是赶上 D+1 发布窗口的唯一保障。

### 6.3 信任指标（新增）

宣传指标不能只统计流量。义卖类内容真正要看的，是**质疑有没有被提前消除**：

| 指标 | 怎么量 | 目标 |
|---|---|---|
| 答疑群"凭什么"类提问 | 群内提问数 | ≤ 5 条 |
| 答疑群回复留存率 | 提出后被回答的比例 | 100% |
| 评论区分歧 | 含"骗钱/不信任/凭什么"关键词 | ≤ 3 条 |
| 收支公示质疑 | 公示后 24h 内相关评论 | 0 条 |

这三项的意义是：**如果活动结束后没人质疑钱，说明公示和背书都做到了位**。比"阅读量涨了"更有价值。

## 八、我们不做的事

写在最后，但很重要：

- **不做"官方推文"以外的付费投放**——预算全部用于物料。
- **不虚构参与人数、不注水销售数据**——如实记录。义卖的价值在于真实。
- **不刷单、不买赞、不找水军**——一次刷出来的数字，会毁掉后面所有的公示。
- **不发绝对化用语的文案**——公益组织出一次合规问题，代价远大于收益。
- **不夸大荣誉、不穷举荣誉**——只写荣誉 PDF 里有的，写"部分公开记录"，不写"共获 XX 奖"。荣誉背书的价值恰恰建立在"第三方可查"上，自己一夸大，这张牌就废了。
- **不把"筹到多少钱"当成唯一 KPI**——真正要沉淀的是**信任**和**可复用的内容资产**。

## 附二：三条线怎么咬合（荣誉背书的落点全景）

```
        疑虑：「你们凭什么把钱交给你们？」
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
   提前预防          现场证实          事后闭环
        │               │               │
  D-7 推文第04章    摊位荣誉墙       D+1 收支公示
  「这支队伍是谁」  06号海报+证书      + 荣誉墙再发一次
        │               │               │
  D-3~D-1 社媒       D-Day 答疑群      D+3 复盘长文
  信任背书分支      荣誉墙甩图        荣誉 + 数据同框
        │               │               │
        └───────────────┴───────────────┘
                        │
                        ▼
              「不是我们说了算，是名单说了算」
```

**关键顺序**：荣誉必须**先于**收支公示出现。公示是在活动后回答"钱去哪了"，荣誉是在活动前回答"你们是谁"。顺序颠倒会让荣誉读起来像事后补救。
