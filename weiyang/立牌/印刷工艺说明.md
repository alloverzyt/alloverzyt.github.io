## 二、成品尺寸、裁切与出血

| 物料 | 成品尺寸（裁切线） | 出血 | 展开尺寸 | 安全边距 |

| 海报A（A2 竖） | 420 × 594 mm | 四边各 3 mm | 426 × 600 mm | ≥ 5 mm（实测左/右 14.0 mm，上 5.6 mm，下 5.6 mm） |
| 海报B（A3 横） | 420 × 297 mm | 四边各 3 mm | 426 × 303 mm | ≥ 5 mm（实测左/右 9.8 mm，上 5.3 mm，下 5.9 mm） |
| 泡沫板立牌 | 600 × 900 mm | 四边各 3 mm | 606 × 906 mm | ≥ 5 mm（实测左/右 33.4 mm，上 15.8 mm） |

**裁切 / 出血规则**

1. 成品尺寸 = 裁切线尺寸；出血 3 mm 属于**可裁掉区域**，不要当作版面留白。
2. **所有背景色块必须做到出血**（海报A 顶部绿区、底部绿色栏；立牌整版绿色背景）。出血区内不要放文字、logo 或需要完整呈现的图形。
3. 海报A / 海报B 底栏、海报B 页眉为满版色块，裁切后应与裁切线齐平、无白边。
4. 立牌展开图中：**红色虚线 = 裁切线**，**蓝色虚线 = 出血线**（均已印在图上，随文件一同送厂，勿自行删图；如需净版请告知印厂按线裁切）。
5. 立牌成品面下方保留 **10 mm 深的深绿底座插槽带**（图中已标注「底座插槽 60mm 宽」）。该带位于裁切线以内，裁切后仍保留，作为插板槽。

## 三、色彩模式与 CMYK

* **交付文件为 sRGB（IEC61966-2.1）8-bit RGB PNG**，已内嵌 sRGB ICC 描述文件；立牌展开图为同色彩空间。
* 印刷厂通常按 **CMYK 工艺（-coated FOGRA39 / JapanColor 2001 Coated）** 拼版。请由印厂按其 **ICC 特性文件** 完成 RGB→CMYK 转换，不要在源文件里预先转 CMYK（会产生双重转换、偏色）。
* 下面的 CMYK 数值是**给印厂做打样比对的参考值**（由 sRGB 数值直算，未做 GCR/UCR 分色），实际以印厂 ICC 转换 + 打样确认为准。

| 颜色 | sRGB | 参考 CMYK (C / M / Y / K) | 用途 |
|---|---|---|---|
| 主绿 | `#57A738` | C48 / M0 / Y66 / K35 | 品牌主色、主标题底、价格带标题、底栏 |
| 深绿 | `#3E8222` | C52 / M0 / Y74 / K49 | 品牌深绿（备用/叠印加重） |
| 中深绿 | `#428626` | C51 / M0 / Y72 / K47 | 大数字（800 / 1500）、价格数字、时间轴 |
| 浅绿 | `#F1F8EC` | C3 / M0 / Y5 / K3 | 浅绿底、说明卡片底 |
| 暖白 / 奶油 | `#FDFBF5` | C0 / M1 / Y3 / K1 | 主背景纸色 |
| 墨色（替代纯黑） | `#23261F` | C8 / M0 / Y18 / K85 | 正文 / 标题文字，**不使用纯 #000** |
| 灰绿（次要文字） | `#6C766A` | C8 / M0 / Y10 / K54 | 副标题、图注 |
| 暖橙（强调色，仅用于小面积） | `#E4842A` | C0 / M42 / Y82 / K11 | 感谢卡左侧竖条（非主色） |

* 大面积满版绿建议 **总墨量 ≤ 300%**，并要求印厂做**实地底色**（solid/实地），避免网点叠印导致的脏边与色偏。
* 满版绿与白字交界处可能有轻微毛边（trap 不足）。如印厂条件允许，建议对绿底块做 **0.2 mm 扩张（overprint/陷印）** 处理。

## 四、纸张 / 板材

| 物料 | 推荐材料 | 工艺 |
|---|---|---|
| 海报A（A2 竖） | **300 g 铜版纸**（单面彩印）；预算有限可用 250 g 铜版纸 | 正面覆 **250 g 哑粉过塑**（哑面，避免反光吃掉字），可选覆 **250 g 亮膜**（更耐久、颜色更饱和但反光强） |
| 海报B（A3 横，摊位桌面展板） | **300 g 铜版纸** 或 250 g 卡纸裱 3 mm KT 板 | 覆哑膜；长期摆放建议裱板 |
| 泡沫板立牌 | **5 mm 雪弗板（PVC 雪弗板）**，表面覆白色喷绘膜（哑光） | 四边 **1 mm 倒角 / 圆角 R5**，底座插槽位由印厂按图模切；插板与底座做 **插销或热熔胶点粘**，不用螺钉 |

* **覆膜建议**：户外/雨天天气 → 覆 **哑膜**（耐水、耐磨、不刺眼）；室内长期展示且追求色彩 → 覆 **亮膜**（更鲜艳，但灯光下有反光）。均建议在**切模之后覆膜**（先裁再覆），可避免覆膜边被裁切时起毛、爆边。
* **雪弗板注意**：雪弗板表面有轻微纹理，喷绘前请印厂先做一张 **A4 小样**确认绿色饱和度；本稿为深绿满版，KT 板建议用深色底板（可定做 5 mm 深绿雪弗板）以免白色 PVC 反光冲淡绿色。

## 六、字体与最小字号

* 中文字体：**Noto Sans CJK SC**（Regular / Medium / Bold）。
  SVG 中以 `font-family="Noto Sans CJK SC"` 与 `font-family="Noto Sans CJK SC Medium"` 声明；`font-weight="700"` 表示 Bold。
  **交付的 SVG 保留 `<text>` 元素（未转曲），请在印厂/设计端安装 Noto Sans CJK SC 后再转曲或改用授权中文字体**（思源黑体 Source Han Sans SC 与 Noto Sans CJK 为同一字形体系，可直接替换，版式不变）。
* 标题采用加大字距（letter-spacing 0.6–1.5 mm），正文不加字距。

## 八、交付与校色建议

1. **先打样再量产**：建议各出 1 张 A4 比例数码打样 + 1 张 A2 实物打样，重点看①绿色是否偏暗/偏黄 ②小字（价格带说明、检查点）是否清晰 ③二维码能否扫出。
2. **绿墨偏色风险**：sRGB 绿转 CMYK 后通常明度上升、饱和度下降；若打样绿发灰，要求印厂提高 **总墨量至 280–300%** 或换用更饱和的绿版。
3. **二维码**：送印前请用手机实扫**打样成品**（非屏幕文件）确认；印厂调图/压缩可能影响识别，必要时单独提供二维码区域做专色实地图。
4. **裁切偏差**：现场海报建议 **三面裁切到 0 保留**（保持 426/600 mm 满版），由印厂按出血线裁切；立牌由印厂按红色裁切线模切，蓝色出血线内缩 3 mm。
5. **文件回传**：请印厂回传 **PDF/X-4（已叠印、已转 CMYK 特性）**，并附 **最终 PDF 缩略图 / 打样照片**存档备查。
